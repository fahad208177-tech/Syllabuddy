# Syllabuddy for Alexa+

Ask whether a topic is on your exam and get the answer from the official syllabus,
with the objective code and the syllabus's own wording: the digital SAT and PSAT,
the ACT, 24 AP courses, the Alberta Diploma and the Singapore A-Level (2,883
learning objectives).

- **Try it:** this page is the simulated Alexa+ experience. Hold the mic (Chrome or Edge) or type.
- **Connect any MCP client:** `https://<this-space>.hf.space/mcp` (Streamable HTTP).
  You'll be asked to link a Syllabuddy account (OAuth 2.1 with PKCE): pick any
  username and a 4 to 8 digit PIN.

Source, tests and documentation: see the GitHub repository linked from the hackathon submission.

Free hosting note: this Space has no persistent disk, so accounts and revision
history reset when it restarts.
